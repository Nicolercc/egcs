# 🧼 Elite Global Cleaning Services (EGCS)

**Certified Experts in Hazardous Materials: Lead, Mold & Asbestos**

Elite Global Cleaning Services (EGCS) specializes in **lead, mold, and asbestos abatement**, as well as high-quality cleaning for both **residential and commercial properties**. Based in New York City, EGCS is dedicated to delivering safe, clean, and compliant environments for every client.

## ⚙️ Installation & Local Development

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/egcs.git

# Navigate into the project directory
cd egcs

# Install dependencies
npm install

# Start the development server
npm run dev
```
